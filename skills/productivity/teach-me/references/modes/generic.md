# Generic lesson

Use only when none of the six specialized modes describes the primary teaching mechanism.

## Choose a visual grammar

Represent the subject as inspectable authored states: timeline, map, comparison, hierarchy, causal flow, state machine, annotated object, or progressive diagram. Start with the smallest meaningful state and reveal one relationship or distinction at a time.

Ground factual claims in frozen high-trust sources. Make observed facts, simplified models, and interpretation visibly distinct. Use at least one deterministic activity that changes what the learner can perceive or predict. Keep decorative controls out.

End with a transfer task that changes the example, constraints, or context. If the lesson becomes primarily about code, a diff, math, algorithms, a document, or a codebase, switch its `meta.ts` mode and follow that reference instead.
