# Design direction

## Thesis

Authored state changes make mechanisms inspectable. The application is a focused technical lesson, not a static article or simulated execution environment.

## Visual world

Light mode uses Notion's warm paper, white cards, quiet dividers, and restrained blue actions. Dark mode uses Vercel's black canvas, near-black elevated surfaces, white type, and sharp hairlines. Geist carries prose. JetBrains Mono Nerd Font Propo carries code.

## Interaction story

The learner opens a full-width lesson, makes a deterministic prediction, steps through semantic state, manipulates the useful representation, inspects frozen citations, retries with specific help, and explicitly marks completion. The lesson drawer starts closed and overlays the page. A pinned teaching annotation opens a separate inspector and closes the drawer.

Motion connects state changes. Reduced motion applies the same state immediately. Visual polish and interactivity take priority over performance scores, but controls must remain responsive and usable.
