# Learner

## Durable preferences

- Reveal systems progressively with diagrams, state transitions, and request/data flows.
- Teach code line by line with the active line, before/after phase, variables, output, and useful conceptual state kept distinct.
- Begin real-valued mathematics with graphs, geometry, parameter exploration, conjectures, counterexamples, and difficult transfer problems.
- Prefer interaction and inspectable state to long prose.

## Fidelity

Never present a simplified mental model as literal runtime behavior. Put `exact`, `simplified`, or `conceptual` beside the state it qualifies.

## Accessibility

Keyboard operation, visible focus, reduced motion, narrow layouts, and resettable interactions are requirements. Add durable user-specific corrections here only after the user states them.
