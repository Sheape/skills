# Pedagogy

Teach one capability tied to the topic mission. Start with a useful question, ask for a deterministic prediction, reveal one meaningful change at a time, give specific feedback, and finish with transfer to a different example.

Every lesson includes at least one required checkable activity. Use stable choices, order, matching, numeric targets, trace predictions, or semantic graph construction. An essay, stepped scene, diagram pan, annotation, or editable scratchpad can support the lesson but cannot satisfy the graded requirement.

Choose the mode from the mechanism taught in this lesson. Code favors authored debugger frames and representative cases. Systems favor progressive data flow and architecture. Real-valued math starts with graphs, parameter exploration, conjecture, boundaries, and difficult transfer.

Coverage is not evidence of learning. Update records only after the learner demonstrates understanding, corrects a misconception, states relevant prior knowledge, or changes the mission.
