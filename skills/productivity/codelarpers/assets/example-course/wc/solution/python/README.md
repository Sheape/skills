# Build your own wc — Python

This repository is your workspace for the **Build your own wc** challenge on codelarpers.

Your program's entry point is `app/main.py`.

1. `codelarper task` prints the current stage's instructions (or open the web UI with `codelarper open`).
2. Implement the stage. `./your_program.sh <args>` runs your program locally.
3. `codelarper test` runs the current stage's tests without committing.
4. `codelarper submit` commits your work and runs the tests. Passing completes the stage.

Failing is part of the method: read the test log, form a hypothesis, change one thing, rerun.
